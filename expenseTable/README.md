# پنل مدیریت هزینه

تمرین هفته اول دوره React: Vite + ESLint + Prettier + کامپوننت `TransactionTable`.

## اجرا

```bash
npm install
npm run dev
```

## دستورها

| دستور            | کار                      |
| ---------------- | ------------------------ |
| `npm run dev`    | اجرای پروژه              |
| `npm run build`  | ساخت نسخه نهایی          |
| `npm run lint`   | بررسی کد با ESLint       |
| `npm run format` | مرتب‌کردن کد با Prettier |

## فایل‌ها

```
src/
├── main.jsx                      شروع برنامه
├── index.css                     رنگ‌ها و استایل کلی
├── data/transactions.js          داده‌های ثابت
└── components/
    ├── TransactionTable.jsx      کامپوننت جدول
    └── TransactionTable.css      استایل جدول
```
